## Galleria precedente 0.7.1

La precedente galleria contiene le due immagini nel [registro 0.7.1](../store-assets/0.7.1/README.md): [Impostazioni](../store-assets/0.7.1/01-impostazioni-it.png) e [Profili](../store-assets/0.7.1/02-profili-it.png). Sono PNG **2562 × 1430**, da catture native CUA del 9 novembre 2026 della build debug **0.7.0**, con interfaccia invariata nella 0.7.1. Lo zoom al **150%** è impostato nell'app: non è un ingrandimento successivo delle immagini. La CLI release 0.7.0 ha convertito gli originali JPEG in PNG senza ridimensionarli. Il registro riporta formato verificato, provenienza e SHA-256. Queste immagini non attestano una build 0.7.1 catturata, installazione del candidato Store, WACK o menu su Windows 10 reale.
