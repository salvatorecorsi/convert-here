# Convert Here 0.8.0 — SVG, audio/video editing and local engines

**0.8.0 candidate**, planned Microsoft Store package **1.0.8.0**. Developer and publisher: **Salvatore Corsi**. This version has not been published, uploaded or submitted to the Store; the final commit and artifacts will be recorded after auditing. The [four new native screenshots](store-assets/0.8.0/README.md) have been captured and verified. [Italiano](release-notes-0.8.0.md).

Recognized input extensions increase to **94** with **static SVG**; there are still **44 outputs**. Integrated resvg rasterizes SVG locally for the image encoders and PDF path. Vectors are not retained and external resources are not fetched. SVGZ, scripts, DTDs, `foreignObject` and embedded images are rejected; size and complexity limits are described in the [conversion guide](conversions.en.md).

The new **audio/video editor** provides a waveform timeline and source frames for video. Adjust the segment with handles or numeric times, and apply gain or mute to compatible conversions. Previews show the source before effects; playback and multitrack editing are not available. Positive gain can clip the signal. For TXT output, the editor applies trimming without gain or mute.

**Settings → Conversion engines** adds buttons to install **Tesseract OCR with Italian and English**, **libheif with HEIC/AVIF decoders and encoders**, and **Whisper CPU with multilingual Tiny**. Engines are optional and are not bundled with the app. Each request shows sources, versions, sizes, licenses and destination before downloading. Archives and models have pinned SHA-256 hashes; extraction, cancellation and publication into the user folder are checked without running the programs during installation. LibreOffice remains separately configured.

**Local audio/video-to-TXT transcription** uses FFmpeg/ffprobe and Whisper. Multilingual Tiny is **77,691,713 bytes**, about **77.69 MB**; the Whisper runtime and model require **87,939,016 bytes**, about **87.94 MB** of downloads, excluding FFmpeg. Requesting Whisper in the GUI also includes FFmpeg if FFmpeg or ffprobe is missing. Language can be detected automatically or selected in settings. Transcripts can contain errors and should be reviewed. Segments are processed on the PC, with temporary files normally removed on completion or cancellation.

The default visible outputs remain **MP3, WAV, JPG, PNG, WebP, GIF, PDF and MP4**. **Enable TXT explicitly in Settings → Output formats → Raw**; audio/video menus display **TXT · Transcription**. Output choices do not reduce recognized inputs. Profiles, queued recipe snapshots, the image editor, A4/A5 pages, PDF Bulk/Merge and history remain available.

The [`portable-packages.json`](../src/runtime_install/portable-packages.json) catalog records runtime versions, URLs, bytes, SHA-256 hashes and selected files. Required DLLs follow the dependency closure. Original notices and verified supplements are retained, with `RUNTIME-SOURCES.json` and `LICENSE-SOURCES.json` in the installation. Original code remains **GPL-3.0-only**; dependencies, fonts, engines and models retain their licenses. See [engine provenance](release-licenses/EXTERNAL-ENGINES.md), [third-party notices](../THIRD-PARTY-NOTICES.md) and the [updated privacy statement](privacy.md).

Local verification reports **393 application tests and 18 DLL tests passed, 411 in total**, plus application all-target Clippy and DLL checks. COM/Invoke with an inert helper, parity for 94 extensions, PowerShell fixtures and actual Italian/English OCR, HEIC/AVIF and MSYS2 Whisper Tiny checks also passed, including the generic CPU variant. These results do not attest an installed new MSIX, a physical Windows 10 host test or WACK. [Testing instructions and limits](store-testing-0.8.0.en.md).

Planned assets are `ConvertHere-0.8.0-windows-x64-setup.exe`, `ConvertHere-0.8.0-windows-x64-portable.zip`, `ConvertHere-0.8.0-source.zip` with vendored Cargo dependencies, and `SHA256SUMS.txt`. Availability, commit, digests and release captures will be recorded after creation and audit. Requirements remain Windows 10 build 19041 or later, x64, including Windows 11. No payment is required to keep using Convert Here.
