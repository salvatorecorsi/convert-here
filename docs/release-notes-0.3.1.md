# Convert Here 0.3.1 — software gratuito, conversioni e OCR locali

Convert Here e gratuito, senza abbonamenti, acquisti in-app o costi a consumo. Le conversioni di formato e l'OCR vengono elaborati sul PC, con selezioni multiple, coda e integrazione con Esplora file.

Funzioni disponibili:

- OCR locale di immagini e scansioni PDF con Tesseract e modelli delle lingue; per i PDF serve anche Poppler.
- Esportazione locale del testo PDF in TXT, Word DOCX e HTML; DOCX e HTML ricostruiscono soltanto il testo.
- PDF Bulk con risultati separati e PDF Merge con ordine delle singole pagine tramite trascinamento o frecce.
- Conversioni native delle immagini, compressione/divisione/unione PDF, Excel/CSV con quattro separatori e documenti Office/HTML in PDF.
- 44 formati di destinazione e 93 estensioni di ingresso nelle categorie compatibili.

FFmpeg, Poppler, LibreOffice, Tesseract e libheif rimangono motori locali opzionali selezionati dall'utente. Non sono inclusi nei pacchetti pubblici. I documenti HTML possono comunque far leggere al motore risorse collegate locali o remote; i link ai siti dei motori si aprono nel browser su richiesta.

Artefatti per Windows x64:

- `ConvertHere-0.3.1-windows-x64-setup.exe`
- `ConvertHere-0.3.1-windows-x64-portable.zip`
- `SHA256SUMS.txt`

La distribuzione GitHub richiede Windows 10 build 19041 o successivo, x64, e offre il menu classico. Il pacchetto Store separato richiede Windows 11 x64. Il setup pubblico resta privo di firma Authenticode; la firma Store segue il percorso di certificazione Microsoft.
