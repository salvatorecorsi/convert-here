# Standard license text used by the notice collector

`SPDX-MIT.txt` is the unchanged MIT standard text from [SPDX license-list-data v3.27.0](https://raw.githubusercontent.com/spdx/license-list-data/v3.27.0/text/MIT.txt), SHA-256 `b05785f9f18e6716bab63424b11454513b9943a222595b70411009202fc592b5` (1078 bytes in the upstream LF file). The collector verifies this hash after normalizing CRLF to LF, so Windows checkout line endings do not change the result.

The collector uses this text for the MIT license declared by the published `libwebp-sys 0.14.4` Cargo package, which has no separate Rust-wrapper MIT notice in its archive. The standard text is labelled as such; it is not described as a recovered upstream `LICENSE`. Its literal `<year>` and `<copyright holders>` fields remain unchanged. No year or copyright owner is supplied by Convert Here. Package author metadata, exact source URL and VCS commit are recorded separately.

The vendored C library's original `COPYING` and `PATENTS` files are collected separately and retained unchanged. This fallback does not replace either file or relicense the component.
